## Description
```
Paste a link, get the whole website as a brand kit in Figma: every image, icon and SVG, the real brand colors, the fonts and type scale — and one-click brand guidelines.

WHAT YOU GET
• Every image, icon, logo, SVG, GIF and video poster — across up to 200 pages (menu, footer and sitemap)
• Full-size HD originals instead of resized thumbnails (WordPress, Shopify, Next.js, Cloudinary, Wix and more)
• Brand colors measured from what the page actually shows: Primary, Secondary, Accent, Dark and Light
• Fonts, weights and the full type scale (H1–H6, body, button)
• Inline SVG icons and logos as editable vectors

ADD TO FIGMA
• Pictures laid out in a clean frame, or one at a time
• Color swatches + color styles, font specimen + text styles
• Create Brand Book: a 16:9 guidelines deck — cover, logo, color, typography, type scale, iconography, imagery — with color variables, text styles and icon components
• Export design tokens (W3C JSON for Tokens Studio, and a Tailwind theme)

MADE FOR DESIGNERS
• Preview large before you take anything (← → to browse, Space to select)
• Download one file or a ZIP
• Your last scan is kept until you start a new one
• Light and dark theme, follows Figma

FAQ
How do I get images from a website into Figma? Paste the link, press Fetch, select the pictures and choose Add to Figma.
How do I find a website's brand colors? GRAB renders the page, measures which colors cover it and which are used on buttons, links and the logo, and names them Primary, Secondary, Accent, Dark and Light.
How do I find out which font a website uses? Open the Fonts section: each typeface, where it is used, its weights and source (Google Fonts, Adobe Fonts or self-hosted).
Can I get SVG icons and logos? Yes — inline SVGs become editable vectors, and the brand book turns them into components.
Does it work on any site? Public pages, yes. Sites that block automated tools or need a login can only be partly read.
Is it free? Yes. No account needed.

Privacy: the links you paste are sent to the GRAB server to read those public pages; nothing from your Figma file is sent. Full policy: https://github.com/umangpatel2191/grab/blob/main/docs/PRIVACY.md
User guide: https://github.com/umangpatel2191/grab/blob/main/docs/USER-GUIDE.md
Support: umangp737@gmail.com

Content you collect belongs to its owners — use it for reference and inspiration, and check the rights before using it in your work.
```

## After publishing: what helps ranking
Figma does not publish its ranking formula. What it shows publicly — and what search uses —
is how well the name, tagline and description match, and how many people use, like and install
the plugin. So:
1. Ask early users to **like** the plugin and leave a comment.
2. Reply to comments; keep the plugin updated (material updates are re-reviewed).
3. Share the Community link (LinkedIn, X, Dribbble, design Slack/Discord groups) and a short demo
   video — a video thumbnail or carousel item also helps.
4. Keep the tagline and first line of the description focused on the main search phrases.
